# Command Line Parser (Лабораторна робота)

Програма `cmd_parce_app` призначена для демонстрації розбору параметрів командного рядка мовою C++ з використанням `getopt_long`.

## Підтримувані ключі:
* `-h` або `--help` : Виклик довідки (Help)
* `-v` або `--version` : Вивід версії програми (Version)
* `-l` або `--list` : Вивід списку (List)

## Особливості:
1. Дублікати ігноруються (наприклад, `-h -h --help` спрацює лише один раз).
2. Об'єднання коротких ключів працює (наприклад, `-lh` розпізнається як `-l` та `-h`).
3. При введенні невідомих ключів (наприклад, `-x`) програма виводить попередження.
